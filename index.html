Frequently Asked Questions

Got questions? We've got clear answers.

How is the distance calculated?

The website uses a locally stored offline distance database. Distances are approximate road distances between district headquarters. No external API is used.

Do I need internet for the distance calculation?

No. The distance database and calculation logic are stored directly inside the website JavaScript.

Are toll fees included?

No. Toll charges and applicable interstate permits should be collected separately as actual charges.

Is driver allowance included?

A flat ₹400 driver allowance is added to the calculated one-way fare.
